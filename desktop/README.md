# 桌面壳

桌面壳使用 Electron 承载现有的资源库网页界面，不改动资源文件和 Python 管线。

漫画阅读器打开后，切换到其他应用或最小化窗口也可以按 `[` / `]` 翻页、
`-` / `=` 切换上一话 / 下一话（沿用阅读器的分类顺序）。关闭阅读器后释放这些系统快捷键。
后台阅读期间这四个裸键由资源库接管；返回应用后仍可在输入框正常输入。
更新桌面主进程或预加载脚本后，需要退出并重新打开桌面端，刷新页面不足以加载它们。

在 `reslib-app` 目录执行：

```powershell
npm ci
npm run build
npm run desktop
```

也可以双击项目根目录的 `启动桌面壳.cmd`；它会构建当前界面并启动当前源码，更新后不会误开旧的便携包。

窗口标题显示当前软件版本，按 `F1` 或按 `Alt` 打开“帮助 → 关于资源库”可查看版本信息。
版本统一来自根目录 `package.json`，桌面端通过 Electron 的 `app.getVersion()` 读取。

它会从应用目录和可执行文件目录向上寻找已有的 `_归档脚本/lib.py`，优先使用该目录下的
`.venv/Scripts/python.exe`。源码项目和便携包都可以放在资源库项目目录下；如果搬到其他位置，
设置 `RESLIB_SCRIPT_DIR` 指向原有的 `_归档脚本`，并按需用 `RESLIB_PYTHON` 指定 Python。
相对的 `RESLIB_SCRIPT_DIR` 以应用目录为基准。显式配置有误时会显示错误，便于修正。
展示服务和订阅服务仅监听 `127.0.0.1`，退出窗口时会一起关闭。

生成 Windows 便携版：

```powershell
npm run desktop:portable
```

输出为 `dist/v<版本>/Moonshadow-Reslib-<版本>-win32-<架构>/Moonshadow-Reslib.exe`，
同目录的 `build-info.json` 记录软件版本、Electron 版本和架构。同版本、同架构的产物已存在时
会停止构建，保留原文件；需要重建时先把旧产物移到其他目录。失败的暂存目录以 `.packaging-` 开头，
保留用于排查，不会替换完整的旧产物。

便携包只包含 Electron、桌面运行文件、后端入口和已构建的前端。它仍需要已有的 Python 运行环境
与 `_归档脚本` 管线；不包含资源文件、登录凭据、本机设置、前端依赖、日志或缓存。
