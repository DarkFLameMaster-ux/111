# 独立桌面程序

资源浏览与资源管理分别打包为 Windows 便携程序。两者使用独立窗口、用户配置目录和实例锁，可同时运行。

- 双击 `启动资源浏览.cmd`，或执行 `npm run desktop:display`，启动浏览、播放与阅读。
- 双击 `启动资源管理.cmd`，或执行 `npm run desktop:management`，启动资源、订阅、刮削和定时管理。
- `npm run desktop:portable` 同时生成两个完整便携目录；各目录中的 `.exe` 是对应入口。

每个程序只启动自己需要的服务。发现已有服务时核对角色、版本后复用，退出时保留被复用的服务。
浏览服务默认 8777，管理服务默认 8781；桌面启动的服务绑定本机。网页启动的浏览服务仍沿用局域网配置。
管理服务承担定时任务，需保持运行；已有计划任务会继续在窗口关闭后提供服务。

便携包输出到 `dist/v<版本>/Moonshadow-<display|management>-<版本>-win32-<架构>/`。
包内只放对应界面、对应服务入口、共享适配代码和 Electron；不包含个人资源或完整 Python 管线。
请保留完整目录。程序向上寻找 `_归档脚本`，也可通过 `RESLIB_SCRIPT_DIR` 和 `RESLIB_PYTHON` 指定。

浏览端漫画阅读器保留后台快捷键：`[` / `]` 翻页，`-` / `=` 换话。
关闭阅读器后释放快捷键；管理程序不接管这些快捷键。窗口标题和帮助菜单显示统一软件版本。
